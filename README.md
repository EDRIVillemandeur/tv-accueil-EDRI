# TV d'accueil EDRI Villemandeur

Tableau de bord plein écran pour la TV Samsung de l'accueil : vidéo YouTube, heure, date, météo, fête du jour et événements.

## Modifier un événement

Ouvrir `events.json` et ajouter un objet au tableau :

```json
{
  "date": "2026-10-15",
  "title": "Nom de l'événement"
}
